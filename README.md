# DeLab

面向设计师的网页设计走查工具。Chrome 浏览器插件，一键点击页面元素即可查看 CSS 样式与盒模型。

## 版本

v0.5 — 页内评论：在任意 DOM 容器上留评论，一键导出给 AI

### v0.5 新增

- 点击任意元素后，框体下方出现圆形评论图标；点它就在元素旁弹出输入框
- 输入框整个容器就是编辑区（无边框）：`回车` 提交，`Esc` 关闭
- 提交后元素右上角出现编号气泡，点气泡可查看评论、标记解决、删除
- 评论详情里的「复制给 AI」输出带选择器、DOM 路径、React 组件的 Markdown
- 评论按页面持久化，刷新后靠元素指纹（选择器 / DOM 路径）重新定位
- 插件激活期间指针替换为 Figma 协作指针（DOM + SVG 绘制，Retina 下锐利）

v0.3 — CSS 检查器 + 盒模型可视化 + 可拖拽浮窗面板

### v0.3 新增

- 浮窗面板可拖拽移动、可缩放，位置和尺寸自动记忆
- 浮窗面板作为唯一面板形态（已移除 DevTools 侧边面板）

### v0.2 新增

- 悬停时四色盒模型覆盖层（content / padding / border / margin），对标 DevTools 配色
- 覆盖层四向 margin / padding 数值标注
- 面板内固定尺寸 Box Model 线框图（可折叠，数值可点击复制）

### v0.1 已有

- 点击插件图标 / 右键菜单激活检查模式
- 悬停 tooltip（标签名 + 尺寸）
- 样式分组展示（文字、间距、尺寸、边框圆角、背景、阴影、布局）
- 色值预览、默认值过滤、复制功能
- 浅色 / 深色主题切换
- Esc 退出检查模式

## 本地加载步骤

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目的 `dist/` 目录
5. 插件安装完成，工具栏出现 DeLab 图标

## 使用方式

- **图标激活**：点击工具栏 DeLab 图标进入检查模式
- **右键激活**：页面任意位置右键 → 「DeLab 检查元素」
- **检查元素**：悬停只显示 2px 实线框；点击锁定后选框常驻，元素下方并排出现「标签名」与评论图标（等高），悬停其他元素不受影响
- **查看样式**：锁定后浮窗展示 Box Model 线框图 + CSS 样式分组列表
- **改参数**：面板内每个值都是可编辑字段，输入即实时生效；`margin / padding` 拆成四边、`border` 拆成宽度 + 线型、圆角拆成四个角；`↑/↓` 步进，`Esc` 回退本次修改，行内 ↺ 单条重置，Header 的 `Reset N` 一键还原
- **盒模型内联编辑**：Box Model 线框图里点击 margin / padding 数值可直接改
- **留评论**：点击任意元素 → 元素下方出现评论图标 → 点开整块都是输入区 → `回车` 提交（`Esc` 取消）
- **看评论**：点元素右上角的编号气泡，可标记解决、删除，或「复制给 AI」
- **交给 AI**：评论详情里点「复制给 AI」，得到带选择器、DOM 路径、React 组件的 Markdown
- **退出**：按 `Esc`（先关评论弹层，再退出插件）或点击面板关闭按钮

## 构建

```bash
npm install
npm run build    # 生产构建
npm run dev      # 开发模式（监听文件变化）
npm run preview  # 构建并起本地预览服务（面板 UI 调试）
```

### 面板 UI 预览

`npm run preview` 之后打开 `http://localhost:5173/preview.html`，可以在不加载扩展的情况下调试面板 UI：
左侧按钮切换被检查的 mock 元素，面板里改值会直接作用在 mock 元素上。改动代码后重新执行 `npm run build` 刷新页面即可。

## 技术栈

- Chrome Extension Manifest V3
- TypeScript + React 18
- Webpack 5
- Shadow DOM 样式隔离
