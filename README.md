# Inspect Lab

面向设计师的网页设计走查工具。Chrome 浏览器插件，一键点击页面元素即可查看 CSS 样式与盒模型。

## 版本

v0.5 — 页内评论：在任意 DOM 容器上留评论，一键导出给 AI

### v0.5 新增

- 点击任意元素后，框体下方出现圆形评论图标；点它就在元素旁弹出输入框
- 输入框整个容器就是编辑区（无边框）：`回车` 提交，`Esc` 关闭
- 提交后元素右上角出现编号气泡，点气泡可查看评论、标记解决（已解决等同删除，不再展示）
- 评论详情里的「复制给 AI」输出带选择器、DOM 路径、React 组件的 Markdown
- 评论按页面持久化，刷新后靠元素指纹（选择器 / DOM 路径）重新定位
- 插件激活期间指针替换为 Figma 协作指针（DOM + SVG 绘制，Retina 下锐利）
- 宽 / 高支持「固定 / 适应 / 填充」三态识别：覆盖 flex 主轴 `flex-grow`、交叉轴 `align-self: stretch`、grid 轨道拉伸、块级流式布局与几何兜底

v0.3 — CSS 检查器 + 盒模型可视化 + 可拖拽浮窗面板

### v0.3 新增

- 浮窗面板可拖拽移动、可缩放；位置与尺寸不做记忆，每次打开回到默认位置（贴右侧）
- 浮窗面板作为唯一面板形态（已移除 DevTools 侧边面板）

### v0.2 新增

- 悬停时四色盒模型覆盖层（content / padding / border / margin），对标 DevTools 配色
- 覆盖层四向 margin / padding 数值标注
- 面板内固定尺寸 Box Model 线框图（可折叠，数值可点击复制）

### v0.1 已有

- 点击插件图标 / 右键菜单激活检查模式
- 悬停高亮框（2px 实线；标签名胶囊在锁定后出现）
- 样式分组展示（文字、间距、尺寸、边框圆角、背景、阴影、布局）
- 色值预览、默认值过滤、复制功能
- 浅色 / 深色主题切换
- Esc 关闭评论弹层 / 大图（不退出插件）

## 本地加载步骤

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 打开右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目的 `dist/` 目录
5. 插件安装完成，工具栏出现 Inspect Lab 图标

## 使用方式

- **图标激活**：点击工具栏 Inspect Lab 图标，直接在新标签页打开该页面的**设备预览工作区**（沿用上次的视口尺寸），不在原页面注入任何 UI
- **右键激活**：页面任意位置右键 → 「Inspect Lab 设备预览」，同样打开工作区
- **检查元素**：在工作区左侧设备画面里悬停 / 点击元素，左侧保持真实手机视口，右侧面板同步样式
- **查看样式**：右侧面板展示 Box Model 线框图 + CSS 样式分组列表；面板可拖拽调宽，也可收成窄轨
- **调视口**：工作区右上角的尺寸控制器可切预设（手机 / 平板 / 笔记本 / 桌面）或自定义宽高；媒体查询、`100vw/vh` 都按设定宽度生效。页面会在工作区里重新加载一次；工作区标签页会临时移除 `X-Frame-Options` / CSP 限制以便嵌入，仍无法嵌入时可一键回退到 `chrome.debugger` 模拟
- **模式与主题**：画布顶部悬浮控件切换走查 / 评论 / 浏览；右上角开关切换明暗模式
- **改参数**：面板内每个值都是可编辑字段，输入即实时生效；`margin / padding` 拆成四边、`border` 拆成宽度 + 线型、圆角默认一个统一值（点右侧按钮可展开成四个角）、不透明度按百分比编辑；`↑/↓` 步进，`Esc` 回退本次修改，行内 ↺ 单条重置，底栏 `Reset N` 一键还原
- **盒模型内联编辑**：Box Model 线框图里点击 margin / padding 数值可直接改
- **量距**：选中元素后按住 `Alt` 悬浮其他元素，显示两者间距（含完全包含时四条边的距离）
- **留评论**：点击任意元素 → 元素下方出现评论图标 → 点开整块都是输入区 → `回车` 提交（`Esc` 取消）
- **看评论**：点元素右上角的编号气泡，可标记解决（等同删除）或「复制给 AI」
- **交给 AI**：评论详情里点「复制给 AI」，得到带选择器、DOM 路径、React 组件的 Markdown
- **退出**：关闭设备预览标签页即可；原页面从头到尾保持原样

## 构建

```bash
npm install
npm run build    # 生产构建
npm run dev      # 开发模式（监听文件变化）
npm run preview  # 构建并起本地预览服务（面板 UI 调试）
```

### 面板 UI 预览

`npm run preview` 之后打开 `http://localhost:5173/preview.html`，可以在不加载扩展的情况下调试面板 UI：
左侧按钮切换被检查的 mock 元素，面板里改值会直接作用在 mock 元素上。改动代码后重新执行 `npm run build` 刷新页面即可。

## 设计资源

`design/icons/label/` 存放面板字段图标的独立 SVG（宽 / 高 / 旋转 / 四向内外边距 / 对齐 / 不透明度 / 圆角四角 / 联动），16×16、路径已去留白，可直接拖入 Figma 编辑；`_sheet.svg` 是带名称的总览版。

## 技术栈

- TypeScript + React 18
- Webpack 5
- Shadow DOM 样式隔离
