## Phase 1：项目基础设施

> 目标：搭建插件骨架，确保项目可本地加载运行

| # | 任务 | 详述 | 产出物 |
|---|---|---|---|
| 1.1 | 初始化项目结构 | 创建目录结构、`package.json`、`tsconfig.json`、构建脚本 | 项目骨架 |
| 1.2 | 编写 Manifest | `manifest.json`，声明 Manifest V3、权限（`activeTab`、`scripting`、`storage`、`contextMenus`）、Content Script 匹配规则 | `manifest.json` |
| 1.3 | 创建 Service Worker | `src/background.ts`，处理工具栏图标点击、右键菜单注册、消息路由 | `src/background.ts` |
| 1.4 | Content Script 入口 | `src/content-script.ts`，实现注入/卸载生命周期，消息监听骨架 | `src/content-script.ts` |
| 1.5 | 构建工具配置 | webpack 打包 TypeScript → dist，支持开发模式 watch | `webpack.config.js` |
| 1.6 | 插件图标 | 工具栏 16/48/128 图标，检查模式激活/非激活两态 | `icons/` |
| 1.7 | 本地加载验证 | `chrome://extensions` 加载 dist 目录，确认 Service Worker 启动、Content Script 注入 | — |

## Phase 2：检查模式核心交互

> 目标：实现元素悬停高亮 + 点击锁定流程

| # | 任务 | 详述 | 产出物 |
|---|---|---|---|
| 2.1 | 检查模式状态机 | 定义状态：`idle` → `inspecting` → `locked`，管理状态切换、副作用清理 | `src/state.ts` |
| 2.2 | 高亮覆盖层 | 绝对定位 `<div>` 覆盖目标元素，蓝色半透明背景 + 描边，跟随元素位置实时更新 | `src/highlight.ts` + `src/styles/highlight.css` |
| 2.3 | Tooltip 实现 | 鼠标悬停时小型浮层，显示标签名 + 计算后尺寸（如 `div · 320 × 48`） | `src/tooltip.ts` |
| 2.4 | 鼠标事件监听 | `mouseover` / `click` 事件，事件捕获阶段处理，阻止穿透 | 集成在 `content-script.ts` |
| 2.5 | Esc 退出 + 清理 | 监听 `keydown` Esc，还原光标，移除所有注入 DOM 元素，状态重置 | 集成在 `state.ts` |
| 2.6 | Service Worker ↔ Content Script 通信 | 图标点击 → 发送消息 → Content Script 切换模式；右键菜单同理 | `background.ts` 消息路由补充 |

---

## Phase 3：侧边抽屉面板 & 样式展示

> 目标：点击元素后展示按分组组织的 CSS 样式

| # | 任务 | 详述 | 产出物 |
|---|---|---|---|
| 3.1 | 面板 DOM 结构 | 侧边抽屉容器（360px 宽，右侧滑出动画），header（元素标签名 + 关闭按钮）+ body（样式列表）+ footer | `src/panel.ts` + `src/styles/panel.css` |
| 3.2 | 样式提取器 | 调用 `getComputedStyle()`，提取 PRD 定义的 7 组属性 | `src/style-extractor.ts` |
| 3.3 | 分组渲染 | 每组可折叠，展开后逐条渲染属性名 + 值，间距以四向 T/R/B/L 展示 | `src/panel-renderer.ts` |
| 3.4 | 色块预览 | 检测颜色值（hex / rgb / rgba / hsl），值旁渲染 18×18px 色块小方块，白色值时加边框 | `src/color-preview.ts` |
| 3.5 | 默认值过滤引擎 | 预置常见 UA default 字典（按 HTML 标签 + 属性），运行时比对，非默认值才展示 | `src/default-values.ts` |
| 3.6 | 显示全部开关 | 面板顶部 toggle，切换后重新渲染（默认值不过滤 vs 过滤） | 集成在 `panel-renderer.ts` |
| 3.7 | 复制功能 | 属性值旁复制按钮（`navigator.clipboard.writeText`）+ 顶部「复制全部」按钮，复制后 toast 提示 | `src/clipboard.ts` |
| 3.8 | 面板开关动画 & 关闭 | 抽屉滑出/滑入过渡动画（`transition`），点击关闭/按 Esc/点击遮罩关闭 | 集成在 `panel.ts` |

---

## Phase 4：辅助功能 & 主题

> 目标：主题切换、跨页面状态保持、交互体验打磨

| # | 任务 | 详述 | 产出物 |
|---|---|---|---|
| 4.1 | 浅色 / 深色主题 | 两套 CSS 变量定义（`--bg`、`--text`、`--border` 等），面板 + tooltip + 高亮层均适配 | `src/styles/variables.css` |
| 4.2 | 主题切换开关 | 面板顶部太阳/月亮图标按钮，点击切换 | 集成在 `panel.ts` |
| 4.3 | 主题持久化 | `localStorage` 存储 `delab-theme`，页面加载时读取；默认跟随 `prefers-color-scheme` | 集成在 `panel.ts` |
| 4.4 | 默认值 filter 状态持久化 | `localStorage` 存储 `delab-show-all` 偏好 | 集成在 `panel.ts` |
| 4.5 | 光标样式切换 | 检查模式时 `cursor: crosshair`（非 pointer-events 区域） | 集成在 `state.ts` |
| 4.6 | 跨页面样式隔离 | 所有注入 DOM 使用 Shadow DOM 包裹，避免被宿主页面 CSS 污染 | 各组件改造 |

## Phase 5：收尾 & 验收

> 目标：按验收标准逐项核验，修复边界问题

| # | 任务 | 详述 |
|---|---|---|
| 5.1 | AC 逐项测试 | 对照 PRD 六章 9 条验收标准，逐项 pass/fail |

| 5.5 | 真实页面走查 | 选取 3-5 个真实网站走查，确保兼容性 |
