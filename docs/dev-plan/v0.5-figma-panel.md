# v0.5 进度记录

## 样式面板 Figma 化（B + C）

**分组重排**（按 Figma 分区）
`Position / Layout / Spacing / Typography / Appearance / Fill / Stroke / Effects`
原 `Color` 组拆分：背景 → Fill，边框色 → Stroke，文字色 → Typography 末尾；`Shape & Effect` 拆为 Appearance（不透明度、圆角）与 Effects（阴影）。

**布局控件**（`LayoutControls`）
- `display` 下拉，选中 flex 系列后才出现方向与对齐
- 方向：4 个箭头分段，点击时自动补 `display: flex`；右侧附换行开关（`flex-wrap`）
- 对齐九宫格：一格同时写 `justify-content` + `align-items`
- 分布：两端 / 环绕 / 均分，对应 `space-between / space-around / space-evenly`

**尺寸三态**（Fixed / Hug / Fill）
- Hug → `fit-content`；Fill → 宽度 `flex: 1 1 0`、高度 `align-self: stretch`
- 回读依据 inline 值与 `flex-grow` / `align-self`

**其他字段**
- 位置组：`position / top / right / bottom / left / z-index`（position 始终显示）
- Layout 补 `flex-wrap`、`align-content`、`flex-grow / shrink / basis`
- 颜色行带透明度百分比（写回 `#rrggbbaa`）
- `isEmptyValue` 按属性区分默认值，避免误伤 `flex-grow: 1`、`top: 0`
