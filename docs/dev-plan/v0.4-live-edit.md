## Phase 1：属性元数据与内联覆盖管理器

| # | 任务 | 详述 | 产出物 |
|---|---|---|---|
| 1.1 | 属性元数据表 | 建立「面板行 → 写入属性 + 编辑器类型」映射：长度、颜色、枚举、数值、简写文本、字体；包含枚举选项、可用单位、默认单位 | `src/property-meta.ts`（新增） |
| 1.2 | `InlineStyleEditor` | 管理当前目标元素的内联样式覆盖：`setTarget(el)`、`apply(name, value)`、`revert(name)`、`revertAll()`、`isModified(name)` | `src/style-editor.ts`（新增） |
| 1.3 | 原始值快照 | 每次写入前记录该属性的原内联值与 `priority`（是否 `!important`）；无内联值时记录「不存在」，撤销时 `removeProperty` | 集成在 `src/style-editor.ts` |
| 1.4 | 写入策略 | 统一 `setProperty(cssProp, value, 'important')`；`background` 写 `background-color`；`border` 写 `border-width` + `border-style`，保留颜色 | 集成在 `src/style-editor.ts` |

### 关键接口

```typescript
export type EditorType = 'length' | 'color' | 'enum' | 'number' | 'text' | 'font';

export interface PropertyMeta {
  /** 实际写入的 CSS 属性（可能是多个） */
  write: string[];
  type: EditorType;
  units?: string[];        // length 类型可用单位
  options?: string[];      // enum 类型选项
  allowEmptyValue?: boolean;
}

export function getPropertyMeta(displayName: string): PropertyMeta;

export class InlineStyleEditor {
  setTarget(el: Element): void;
  apply(displayName: string, value: string): boolean; // 返回是否合法并已应用
  revert(displayName: string): void;
  revertAll(): void;
  isModified(displayName: string): boolean;
  modifiedNames(): string[];
}
```

## Phase 3：实时预览、撤销与全部还原

| # | 任务 | 详述 | 产出物 |
|---|---|---|---|
| 3.1 | 输入即应用 | `onChange` 内校验并调用 `InlineStyleEditor.apply`；用 `requestAnimationFrame` 合并同帧多次写入 | `src/components/PropertyRow.tsx` |
| 3.2 | 提交规范化 | 提交时重新读取 `getComputedStyle`，把 `16` 规范化为 `16px`、把颜色规范化回展示格式 | `src/components/FloatingPanel.tsx` |
| 3.3 | 撤销 / 全部还原 | 单行撤销调用 `revert(name)`；顶部 `Reset all` 调用 `revertAll()` 并作废计数 | `src/components/FloatingPanel.tsx`、`src/style-editor.ts` |
| 3.4 | 修改计数 | 顶部展示 `N changed`；数据由 `modifiedNames().length` 提供 | `src/components/FloatingPanel.tsx` |

### 数据流

```
PropertyRow.onChange(name, value)
  → 校验（property-meta + CSS.supports）
  → InlineStyleEditor.apply(name, value)
  → 目标元素内联样式更新（页面即时预览）
  → 通知 FloatingPanel 刷新 modified 集合
  → 提交时重新 extract()，回填规范化展示值
```

> 编辑过程中不重新 `extract()` 全量刷新，避免输入框失焦；仅在提交/撤销时刷新。

## 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 提交时全量刷新导致输入框失焦 | 编辑体验中断 | 编辑中只做 apply，不重渲染；提交后再刷新 |
| 计算值 → 可写值语义不一致 | 写入后效果与预期不同 | 用 `CSS.supports` 校验，并以重新计算后的值为准 |
| `background` / `border` 简写误伤 | 丢失背景图或边框颜色 | 写入具体长属性，禁止写复合简写 |
| 页面已有 `!important` 规则 | 修改不生效 | 内联 `!important` 覆盖；仍失败时行内提示 |
| 元素切换后修改记录串味 | 撤销作用到错误元素 | 记录按元素（WeakMap / Map<Element, Record>）隔离 |
| 大量输入触发频繁重排 | 页面卡顿 | rAF 合帧；仅在提交时重新读取 computedStyle |
