## Phase 1：盒模型数据提取 & 覆盖层渲染

> 目标：实现四色盒模型覆盖层，对标 DevTools 悬停效果

| # | 任务 | 详述 | 产出物 |
|---|---|---|---|
| 1.1 | `StyleExtractor` 新增 `getBoxModel()` | 增加 `getBoxModel(element)` 方法，一次性返回 margin / padding / border 四向 `number` 值（parseFloat 去 px），以及 content 的 `getBoundingClientRect` | `src/style-extractor.ts`（补充） |
| 1.2 | 盒模型覆盖层组件 `BoxModelOverlay` | 4 层绝对定位 `<div>`：margin（橙 transparent）、border（黄 transparent）、padding（绿 transparent）、content（蓝 transparent）。所有层 `pointer-events: none`，z-index 从外到内递增。提供 `show(target) / hide() / destroy()` | `src/box-model-overlay.ts` |
| 1.3 | 覆盖层数值标注 | 在 margin 和 padding 区域的四边中心渲染 `<span>` 标注，文字居中于各区域边中。0 值不显示标注。字号 10px 加粗，黑色/白色根据主题背景切换 | 集成在 `src/box-model-overlay.ts` |
| 1.4 | 覆盖层样式 | 四层颜色定义、标注字体样式、动画过渡。覆盖层颜色固定（对标 DevTools），不随主题变化 | `src/styles/box-model.css` |
| 1.5 | `content-script.ts` 集成覆盖层 | 将 `highlight` 替换为 `boxModelOverlay`，`handleMouseOver` 中调用 `boxModelOverlay.show(target)` 替换原有 `highlight.show(target)`。复用已有 80ms debounce 机制 | `src/content-script.ts`（修改） |

### Phase 1 关键实现细节

**`getBoxModel()` 返回结构：**
```typescript
interface BoxModel {
  margin:  { top: number; right: number; bottom: number; left: number };
  border:  { top: number; right: number; bottom: number; left: number };
  padding: { top: number; right: number; bottom: number; left: number };
  content: { width: number; height: number };
}
```

**覆盖层定位计算（以 margin 层为例）：**
```
top    = rect.top - margin.top
left   = rect.left - margin.left
width  = rect.width + margin.left + margin.right + border.left + border.right + padding.left + padding.right
height = rect.height + margin.top + margin.bottom + border.top + border.bottom + padding.top + padding.bottom
```

padding 层类似向内缩进 margin，border 层向内缩进 padding，content 层为 `getBoundingClientRect` 结果。
