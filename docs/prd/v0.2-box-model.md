## 二、功能详述：盒子模型可视化

### 2.1 盒子模型覆盖层（Hover 态）

#### 2.1.1 目标效果

对标 Chrome DevTools 元素选择器，当鼠标悬停在元素上时，不再仅高亮元素内容区（蓝色半透明），而是分层渲染盒子模型：

```
┌────────────────────────────────────┐
│         margin（橙色/浅橙）          │
│  ┌──────────────────────────────┐  │
│  │      border（黄色/浅黄）       │  │
│  │  ┌────────────────────────┐  │  │
│  │  │   padding（绿色/浅绿）   │  │  │
│  │  │  ┌──────────────────┐  │  │  │
│  │  │  │                  │  │  │  │
│  │  │  │  content（蓝）    │  │  │  │
│  │  │  │                  │  │  │  │
│  │  │  └──────────────────┘  │  │  │
│  │  └────────────────────────┘  │  │
│  └──────────────────────────────┘  │
└────────────────────────────────────┘
```

#### 2.1.2 颜色方案

| 区域 | 颜色 | 透明度 | 对应 CSS |
|---|---|---|---|
| Content | `#4285F4`（蓝） | 40% | content-box |
| Padding | `#34A853`（绿） | 30% | padding-box |
| Border | `#FBBC04`（黄） | 40% | border-box |
| Margin | `#EA4335`（橙） | 20% | margin-box |

颜色对标 Chrome DevTools 盒模型配色，降低设计师认知成本。

#### 2.1.3 实现策略

- 使用 **4 层绝对定位 div**，分别渲染 content、padding、border、margin 区域
- 所有层 `pointer-events: none`，不干扰鼠标事件
- 层级关系：margin → border → padding → content（从外到内，底层在上）
- 通过 `getComputedStyle` 获取元素 padding / border / margin 实际计算值
- 通过 `getBoundingClientRect` 计算各层位置和尺寸

各层定位计算：

```
content-box:  target.getBoundingClientRect()

padding-box:  rect.left - paddingLeft,    rect.top - paddingTop,
              rect.width + paddingLeft + paddingRight,
              rect.height + paddingTop + paddingBottom

border-box:   在 padding-box 基础上往外扩展 border-width

margin-box:   在 border-box 基础上往外扩展 margin-top/right/bottom/left
```

#### 2.1.4 标注数字

在 margin 和 padding 区域的四条边中心位置显示数值标注：

- 标注以绝对定位 `<span>` 实现，居中于对应边
- 标注文字：黑色/白色（根据主题），字号 10px，加粗
- padding 标注在 padding 区域中心
- margin 标注在 margin 区域中心
- 若数值为 0，optional 隐藏标注（减少视觉噪音）

示例标注布局：
```
                          margin-top: 20px
            ┌───────────────────────────────────┐
            │                                   │
  m-l:16px │    padding-top: 8px               │ m-r:16px
            │  ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┐   │
            │  p-l:8px│              │p-r:8px   │
            │         └ ─ ─ ─ ─ ─ ─ ─ ─ ─       │
            │     padding-bottom: 8px           │
            └───────────────────────────────────┘
                         margin-bottom: 20px
```

### 2.2 悬停 tooltip（保持 v0.1 风格）

```
div · 320 × 48
```

Tooltip 保持简洁，仅展示元素标签名和内容区尺寸，不做线框图展示。盒模型信息通过页面覆盖层标注和面板线框图呈现即可。

### 2.3 面板内盒模型线框图

#### 2.3.1 位置

锁定元素后，在侧边抽屉面板**顶部**（样式列表之前）展示盒模型线框图。

#### 2.3.2 布局

固定尺寸的嵌套色块模型，不按实际比例缩放。每层左上角标注层名称（margin / border / padding），四边中点标注数值：

```
┌──────────────────────────────┐
│  Box Model            [−]    │
├──────────────────────────────┤
│  ┌──────────────────────────┐│
│  │margin      20            ││
│  │   ┌────────────────────┐ ││
│  │   │border       1      │ ││
│  │   │  ┌──────────────┐  │ ││
│  │   │  │padding  8    │  │ ││
│  │   │  │  ┌────────┐  │  │ ││
│  │   │  │  │320×48  │  │  │ ││
│  │   │  │  └────────┘  │  │ ││
│  │   │  │ 8            │  │ ││
│  │   │  └──────────────┘  │ ││
│  │   │ 1                  │ ││
│  │   └────────────────────┘ ││
│  │20                        ││
│  └──────────────────────────┘│
└──────────────────────────────┘
```

#### 2.3.3 交互细节

- 默认展开，可通过 header 折叠/展开
- 四向数值从 `getComputedStyle` 提取，精确到整数 px
- 数值始终显示（包括 0），面板内信息完整性优先
- 数值 hover 高亮，点击复制为 `Npx`
- 每层左上角显示层名称标签（margin / border / padding），方便识别

## 三、技术方案

### 3.1 新增文件

```
src/
├── box-model-overlay.ts    # 盒模型四层覆盖层 + 标注
├── box-model-tooltip.ts    # 悬停 tooltip（保持 v0.1 风格）
├── box-model-diagram.ts    # 面板内固定尺寸盒模型线框图
```

### 3.2 改动文件

| 文件 | 改动 |
|---|---|
| `content-script.ts` | 集成 BoxModelOverlay + BoxModelTooltip 替换原 Highlight + Tooltip |
| `state.ts` | 新增 `InspectState` 相关事件钩子（无状态新增） |
| `panel-renderer.ts` / `inline-panel.ts` | 面板顶部插入盒模型线框图 |
| `style-extractor.ts` | 新增 `getBoxModel()` 方法，返回 margin/padding/border 四向值 |
| `webpack.config.js` | 无变动（自动识别新 entry） |

### 3.3 数据提取

通过 `window.getComputedStyle(element)` 一次性获取以下属性：

```typescript
// margin
marginTop, marginRight, marginBottom, marginLeft
// padding
paddingTop, paddingRight, paddingBottom, paddingLeft
// border
borderTopWidth, borderRightWidth, borderBottomWidth, borderLeftWidth
// content
width, height
```

所有值解析为 `number`（去掉 "px" 后缀），0 值保留。

### 3.4 覆盖层监听策略

覆盖层在当前鼠标事件体系下被动响应，不新增事件监听：

- 由 `handleMouseOver` 驱动更新目标元素引用
- 覆盖层内部使用 `requestAnimationFrame` 避免 layout thrashing
- 复用已有 debounce 机制（80ms delay）

### 3.5 主题适配

- 覆盖层颜色固定（对标 DevTools），不随主题变化
- 标注文字颜色根据背景明暗自动切换
- 面板内线框图使用 CSS 变量适配主题

## 五、交互流程变更

### 5.1 更新后用户流程

```
激活插件 ─→ 进入检查模式（光标变为十字准星）
        ─→ 鼠标悬停时：
            · 四色盒模型覆盖层显示（content/padding/border/margin）
            · 覆盖层四向标注 padding/margin 数值
            · 增强浮窗显示：标签名 + 盒模型线框图
        ─→ 点击元素，锁定当前元素
        ─→ 右侧滑出面板：
            · 顶部：盒模型线框图（可折叠，数值可复制）
            · 下方：CSS 样式分组列表（同 v0.1）
        ─→ 按 Esc 或点击关闭按钮退出检查模式
```

### 5.2 与 v0.1 的兼容

- 原 Highlight（蓝色半透明覆盖层）被 BoxModelOverlay 取代
- 原 Tooltip（纯文本标签名+尺寸）被 BoxModelTooltip 取代
- 面板结构不变，仅顶部插入盒模型线框图 section
- 所有 v0.1 acceptance criteria 在 v0.2 中依然成立

## 六、验收标准（Acceptance Criteria）

1. 鼠标悬停时，元素显示四色盒模型覆盖层（content 蓝、padding 绿、border 黄、margin 橙）
2. 覆盖层上标注 margin 和 padding 的四向数值（0 值可隐藏）
3. 覆盖层实时跟随元素位置，数值与实际 `getComputedStyle` 一致
4. 悬停浮窗展示盒模型线框图，四向标注 margin/padding/border/content 数值
5. 点击锁定元素后，面板顶部展示盒模型线框图
6. 线框图默认展开，可通过 header 折叠/展开
7. 线框图中数值可点击复制
8. 覆盖层和线框图颜色方案对标 Chrome DevTools
9. 盒模型可视化与 v0.1 所有功能并存，无回归问题
10. 浅色 / 深色主题下盒模型线框图正常显示
11. 按 Esc 退出检查模式后，所有盒模型覆盖层和浮窗正确清除
