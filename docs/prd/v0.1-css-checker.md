## 一、产品概述

### 1.1 产品定位

面向设计师的设计走查验收工具。让设计师无需打开 Chrome DevTools，一键点击页面元素即可查看 CSS 样式，降低设计走查门槛。

### 1.2 核心价值

- 以设计语言展示 CSS 属性，设计师无需理解技术细节
- 去除 DevTools 庞杂信息，聚焦视觉相关属性
- 快速定位颜色、字体、间距等关键设计参数

### 1.3 目标用户

| 优先级 | 用户角色 | 场景 |
|---|---|---|
| 主要 | UI / UX 设计师 | 设计稿还原度验收走查 |
| 次要 | 产品经理 | 快速查看页面样式参数 |
| 辅助 | 前端开发者 | 日常开发中快速检查样式 |

### 1.4 用户痛点

- DevTools 信息过于庞杂，设计师难以快速定位关键样式
- 缺乏面向"视觉属性"（颜色、字体、间距、圆角等）的友好展示
- 样式值缺乏可视化预览（如颜色无色块）

## 二、功能详述：CSS 检查器

### 2.1 用户流程

```
激活插件 ─→ 进入检查模式（光标变为十字准星）
        ─→ 鼠标悬停时高亮元素 + 显示 tooltip（标签名 / 尺寸）
        ─→ 点击元素，锁定当前元素
        ─→ 右侧滑出侧边抽屉面板，展示 CSS 样式
        ─→ 按 Esc 或点击关闭按钮退出检查模式
```

### 2.2 激活方式

- **方式一**：点击浏览器工具栏 DeLab 图标，进入检查模式
- **方式二**：页面任意位置右键 → 「DeLab 检查元素」

两种方式同时支持。

### 2.3 面板呈现

- **形态**：右侧侧边抽屉（滑出式）
- **宽度**：固定宽度（如 360px）
- **层级**：覆盖在页面上方，不影响页面布局
- **关闭**：点击面板关闭按钮 / 按 Esc / 再次点击工具栏图标

### 2.4 元素交互

| 操作 | 行为 |
|---|---|
| 鼠标悬停 | 高亮当前元素（蓝色半透明覆盖层），显示 tooltip（标签名 + 尺寸） |
| 点击元素 | 锁定元素，侧边抽屉展开，展示该元素样式 |
| 锁定后悬停 | 不再切换，直到再次点击其他元素或取消锁定 |
| 按 Esc | 退出检查模式，关闭面板，恢复光标 |

### 2.5 样式展示内容

#### 分组策略

| 分组 | 包含 CSS 属性 |
|---|---|
| **文字** | `font-family`、`font-size`、`font-weight`、`line-height`、`letter-spacing`、`color`、`text-align` |
| **间距** | `margin`（四向展开）、`padding`（四向展开） |
| **尺寸** | `width`、`height`、`max-width`、`max-height` |
| **边框与圆角** | `border-width`、`border-style`、`border-color`、`border-radius` |
| **背景** | `background-color`、`background-image`、`background-size` |
| **阴影** | `box-shadow`、`text-shadow` |
| **布局** | `display`、`flex-direction`、`justify-content`、`align-items`、`gap`、`position` |
| **其他** | `opacity`、`cursor`、`overflow` |

#### 展示规则

- **默认模式**：仅展示非浏览器默认值（过滤 UA stylesheet 默认值），保持清爽
- **完整模式**：提供「显示全部」开关，可切换展示所有 computed 值

#### 视觉增强

- **颜色值**：色值文本旁展示色块预览（小方块，含边框区分白色）
- **间距**：margin / padding 四向值以直观方式展示（top / right / bottom / left）

### 2.6 复制功能

- **单属性复制**：每个属性值旁有复制按钮，点击复制该属性值
- **全局复制**：面板顶部「复制全部」按钮，一键复制所有展示样式

### 2.7 主题切换

- 支持浅色 / 深色主题
- 切换按钮置于面板顶部
- 偏好通过 `localStorage` 持久化
- 默认跟随系统偏好

## 三、功能范围边界

### MVP 包含

- [x] Computed Style 展示（按设计维度分组）
- [x] 元素高亮 + 悬停 tooltip
- [x] 点击选择元素
- [x] 侧边抽屉面板（右侧滑出）
- [x] 色值色块预览
- [x] 单属性值 / 全部复制
- [x] 默认值过滤 + 显示全部开关
- [x] 浅色 / 深色主题切换

- [ ] 样式规则来源追溯（inline / file / line）
- [ ] 响应式 / 多设备模拟
- [ ] 导出图片 / 截图
- [ ] 历史记录 / 收藏
- [ ] Firefox / Edge 支持
- [ ] 元素层级快捷键切换（↑↓）
- [ ] 伪元素样式检查（后续版本考虑）

## 四、技术方案概要

| 项 | 方案 |
|---|---|
| 插件规范 | Chrome Extension Manifest V3 |
| 面板实现 | Content Script 注入，DOM 绘制侧边抽屉 |
| 元素高亮 | 绝对定位的覆盖层 `<div>`，蓝色半透明背景 |
| 样式获取 | `window.getComputedStyle(element)` |
| 默认值过滤 | 预置常见浏览器默认样式字典 + 运行时比对 |
| 主题系统 | CSS 变量实现，`localStorage` 持久化偏好 |
| 组件 | 原生 HTML + CSS + TypeScript（无框架依赖） |

### 插件结构（预期）

```
DeLab/
├── manifest.json          # 插件配置
├── src/
│   ├── background.ts      # Service Worker
│   ├── content-script.ts  # 主逻辑（检查器）
│   ├── panel.ts           # 侧边抽屉面板
│   └── styles/
│       ├── panel.css      # 面板样式
│       └── highlight.css  # 高亮覆盖层样式
├── icons/                 # 插件图标
└── assets/                # 静态资源
```

## 六、验收标准（Acceptance Criteria）

1. 点击工具栏图标或右键菜单，能成功进入 CSS 检查模式
2. 鼠标悬停时，元素显示蓝色半透明高亮和尺寸 tooltip
3. 点击元素后，右侧滑出样式面板，显示按分组组织的 CSS 属性
4. 样式面板默认展示非默认值，切换开关后可查看全部
5. 颜色值旁有色块预览
6. 支持单属性复制和全部复制
7. 支持浅色 / 深色主题切换，刷新后保持偏好
8. 按 Esc 或点击关闭能退出检查模式，页面恢复原状
9. 任意 HTTPS 页面可正常使用
