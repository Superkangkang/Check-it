## 一、版本概述

### 1.1 版本目标

把面板从「只读查看器」升级为「就地调参器」：面板里每一个参数都可以直接编辑，编辑结果立刻作用在当前页面上，设计师不必改代码、不必开 F12 就能试出正确的间距、字号、颜色。

### 1.2 前置版本已有能力（保留不变）

- 图标 / 右键激活检查模式，悬停四色盒模型覆盖层 + 尺寸 tooltip
- 点击锁定元素，浮窗面板展示 Box Model 线框图 + 分组样式列表
- 面板可拖拽、可缩放，位置尺寸记忆
- 色值预览、默认值过滤、Show all、点击复制、Hex/RGB/HSL 切换、明暗主题

### 1.3 v0.4 新增能力

| # | 功能 | 说明 |
|---|---|---|
| 1 | 参数常驻可编辑 | 每个参数默认就是一个输入框（参考 Figma 检查器），不需要先点开编辑态 |

| 3 | 控件按属性适配 | 长度用数字输入、颜色用取色器 + 文本、枚举用下拉、简写拆成四边 / 三段 |

## 二、与 F12 DevTools 的行为对照

先明确一个关键问题：**DevTools 里改样式属于哪种机制**，这直接决定本版本的技术路线。

F12 Styles 面板里有两类修改：

| 修改位置 | 机制 | 影响范围 | 页面刷新后 |
|---|---|---|---|
| `element.style { }` 内联块 | 直接改元素的 `style` 属性 | 仅当前元素 | 丢失 |
| 带选择器的规则（如 `.card { padding: 20px }`） | 修改内存中该样式表的 CSSOM | 所有匹配该规则的元素 | 丢失 |

两种都是「改在内存里、刷新即失效」，但第二类需要知道「这个值来自哪条规则、被谁覆盖」，这只能通过 DevTools 协议的 CSS 域拿到。插件的浮窗面板拿不到（`chrome.devtools.*` 仅在 DevTools 打开时可用，v0.3 已移除 DevTools 侧面板形态）。

**因此 v0.4 采用等价于第一类的方式：写元素 inline style。**

由此产生的行为约定：

- 优先级等同 `element.style`，高于普通样式表规则，但低于 `!important` 与进行中的动画 / 过渡
- 只影响当前锁定元素，不会波及其他同类元素
- 修改常驻页面，退出检查模式、关闭面板都**不自动还原**，刷新页面即恢复原样（与 DevTools 一致）
- 还原靠面板里的「重置」，不靠退出

> 若后续需要「改规则、改所有同类元素」，需要重新引入 DevTools 页面形态（`devtools_page` + CDP CSS 域），不在本版本范围。

## 三、功能详述

### 3.1 编辑入口（参考 Figma 检查器）

**每个参数默认就是一个输入框，没有「进入编辑态」这一步。**

- 字段：浅色填充、4px 圆角、24px 高、无默认边框；hover 出现边框，聚焦时边框变为强调色
- 编辑即生效：输入过程中只要浏览器认可该值，就立刻写入页面（Figma 式实时预览）
- `Enter` 失焦确认；`Esc` 回退到本次聚焦前的值并失焦；失焦时非法值丢弃并恢复页面当前值
- 数值类字段 `↑/↓` 步进 ±1，`Shift + ↑/↓` ±10
- `Tab` 在各字段间顺序移动，可直接连续调整多个参数
- 行 hover 时右侧出现小图标：未修改为「复制」，已修改为「重置 ↺」
- 已修改行：行首 2px 强调色竖条；标签 hover 显示原始值

面板本身位于 Shadow DOM，点击不会误触页面上的元素锁定逻辑。

### 3.2 控件类型映射

| 控件 | 适用属性 | 交互 |
|---|---|---|
| `length` | width / height / font-size / line-height / letter-spacing / gap / 圆角 | 数字输入 + 单位跟随原值（px / % / em / rem）；↑↓ ±1，Shift+↑↓ ±10 |
| `number` | opacity / font-weight | 数字输入，opacity 附加 0–1 滑块 |
| `color` | color / background / border-color | 原生取色器 + 文本输入，hex / rgb / hsl 互认；组内 Hex/RGB/HSL 显示切换保持不变 |
| `enum` | display / flex-direction / justify-content / align-items / text-align / position | 下拉，含常用候选 + 「自定义…」 |
| `text` | box-shadow / 其他自由值 | 文本框，`CSS.supports()` 校验，非法值不写入 |
| 多值拆解 | margin / padding / border / border-radius / gap | 一行拆成多个独立输入框，见 3.3 |

不可编辑项（只读）：`font`（渲染字体探测结果）默认只读；Box Model 线框图里的 content 尺寸只读（由内容或 width/height 决定）。

### 3.3 多值属性的拆解

简写属性不再以 CSS 语法的形式展示，而是拆成多个独立输入框（展示形态与 CSS 写法不必一致）：

| 属性 | 拆解方式 | 字段前缀 |
|---|---|---|
| margin | 上 / 右 / 下 / 左 四个输入框 | `T` `R` `B` `L` |
| padding | 上 / 右 / 下 / 左 四个输入框 | `T` `R` `B` `L` |
| border | 宽度（数值）+ 线型（下拉） | `W` `S` |
| border-radius | 四个圆角 | `↖` `↗` `↘` `↙` |
| gap | 行间距 / 列间距 | `R` `C` |

写入规则：

- 每个子字段写对应的长属性（`margin-top`、`border-top-left-radius` …），单改一边不会覆盖其他边
- 行内 `↺` 会一次还原该行的全部子字段
- 行的复制仍输出合并后的简写（`margin: 16px 0px`），方便贴回代码
- 只读项（如 `font`）与单值属性（`box-shadow`、`line-height`）保持单个输入框

### 3.4 实时预览链路

```
面板提交
  → StyleWriter.apply(el, cssProp, value)
      ├─ CSS.supports(prop, value) 校验，非法直接拒绝
      ├─ el.style.setProperty(prop, value)
      └─ 读回 computed 校验是否真的生效，未生效则带 !important 重试一次
  → requestAnimationFrame 合并同一帧内的多次编辑
      ├─ StyleExtractor.extract(el) 重新取值（叠加 EditSession 的修改，保证显示即所见）
      ├─ StyleExtractor.getBoxModel(el) 重算
      └─ panel.showData(...) 刷新面板
  → 覆盖层 / 线框图 / tooltip 按新尺寸重绘
```

要点：

- 改 width / padding 会让元素位移与重排，覆盖层必须重算，不能复用旧 rect
- 面板自身绘制在 Shadow DOM 内，不受页面样式影响，也不会因为重排闪动
- 连续按方向键调整时用 rAF 合并，避免每按一次都完整重渲染

### 3.5 重置

| 层级 | 入口 | 行为 |
|---|---|---|
| 单条 | 行 hover 的 ↺ | 该属性（多值属性含全部子字段）恢复原始 inline 值；若原始值来自样式表则 `removeProperty` |
| 全部 | Header 的 `Reset N` | 按首次编辑时保存的 `style` 属性快照整串还原，一次撤销本元素所有修改 |

- `Reset N` 仅在存在修改时出现，N 为当前元素已修改的声明条数（四边拆解按子字段计数）
- 重置后同样触发一次重新取值与重绘

### 3.6 盒模型内联编辑

Box Model 线框图里的 margin / padding 四向数值可直接点击编辑：

- 点击数值 → 原位变成 40×16 的小输入框，回车 / 失焦提交，Esc 取消
- 输入纯数字自动补 `px`，写入对应长属性（`margin-top` 等），与列表行共用同一套会话与刷新逻辑
- border 宽度与 content 尺寸保持只读

### 3.7 异常与边界

| 场景 | 处理 |
|---|---|
| 输入非法值（如 `width: abc`） | `CSS.supports` 拦截，输入框标红并保留，不写入页面；Esc 或再次失焦恢复 |
| 原值来自 `!important` 规则 | 普通 inline 不生效 → 自动带 `!important` 重试；仍不生效则该行标「未生效」小圆点 |
| 属性值由 CSS 变量驱动 | 改的是计算后的字面值，不改变量本身；面板中正常显示与编辑 |
| 伪类态（:hover / :focus） | 不支持编辑，仅展示当前静态计算值 |
| 伪元素（::before / ::after） | 不支持，v0.4 范围外 |
| 元素被页面脚本重渲染 | 编辑记录绑定的元素可能被替换；重新点击选中即可重新建立会话 |
| 有 transition 的元素 | 修改会带过渡动画，预览略滞后，属预期（不临时禁用过渡） |

## 四、技术方案

### 4.1 数据模型

`StyleProperty` 扩展（保持向后兼容，新字段可选）：

```ts
export type ControlType =
  | 'length' | 'number' | 'color' | 'enum' | 'text'
  | 'box-sides' | 'border' | 'radius';

export interface StyleProperty {
  name: string;          // 展示名，如 'margin'
  value: string;         // 当前生效值（已叠加编辑）
  isColor: boolean;
  control: ControlType;
  cssProps: string[];    // 实际写入的属性，如 ['margin-top','margin-right',...]
  unit?: string;         // 'px' | '%' | 'em' | 'rem' | ''
  options?: string[];    // enum 候选
  modified?: boolean;    // 是否被编辑过
  original?: string;     // 原始值，用于展示与单条重置
  readOnly?: boolean;    // font 等只读项
}
```

编辑会话（新文件 `src/edit-session.ts`）：

```ts
interface EditRecord {
  cssProp: string;
  originalInline: string | null;  // null 表示原值来自样式表，重置用 removeProperty
  value: string;
}

class EditSession {
  element: Element;
  styleSnapshot: string | null;          // 首次编辑时的 style 属性整串快照
  records: Map<string, EditRecord>;
  apply(prop: string, value: string): boolean;
  reset(prop: string): void;
  resetAll(): void;
  has(prop: string): boolean;
  count(): number;
}
```

### 4.2 新增文件

```
src/
├── edit-session.ts        # 单元素编辑会话：快照、记录、单条 / 全部还原
├── style-writer.ts        # 校验 + 写 inline + 生效性验证 + 简写合成
├── property-controls.ts   # 属性 → 控件类型 / 单位 / 枚举候选 的映射表
└── components/
    ├── PropertyField.tsx   # 常驻可编辑字段（输入 / 下拉 / 取色 + 校验 + 步进）
    └── BoxSidesEditor.tsx  # margin / padding / border 的展开编辑
```

### 4.3 改动文件

| 文件 | 改动 |
|---|---|
| `src/style-extractor.ts` | `StyleProperty` 增加 control / cssProps / unit / options / modified / original；`extract` 接受可选 `EditSession`，用于覆盖展示值与标记修改 |
| `src/components/PropertyRow.tsx` | 值区域改为可点击进入编辑；hover 工具图标（复制 / 重置）；修改态样式 |
| `src/components/StylePanel.tsx` | 透传 `onCommit` / `onReset` / `session`，渲染已修改统计 |
| `src/components/BoxModelDiagram.tsx` | 四向 margin / padding 与 radius 数值可就地编辑（复用同一个 writer） |
| `src/components/FloatingPanel.tsx` | 持有当前元素与 EditSession，提交后重新取值并重绘；Header 增加重置全部 |
| `src/components/Header.tsx` | 新增「重置全部 + 修改数量」按钮 |
| `src/content-script.ts` | 锁定元素时创建 / 切换 EditSession；编辑提交后触发覆盖层与线框图重算 |
| `manifest.json` / `package.json` | 版本号升至 0.4.0 |
| `docs/property-groups.md` | 补充每个属性的控件类型与是否可编辑 |

### 4.4 关键实现约束

- **不要改 React state 驱动页面元素**：页面元素由 StyleWriter 直接写 DOM，React 只负责面板 UI，避免两套渲染互相打架
- **写入用长属性**：简写属性一律拆成 `-top/-right/-bottom/-left` 写入，避免覆盖未编辑的边
- **首次编辑才快照**：`styleSnapshot` 在第一次编辑时记录，保证「重置全部」还原到干净状态
- **显示以 computed 为准**：每次编辑后重新 `getComputedStyle`，而不是把输入值直接显示，避免浏览器把 `1.2` 规范成 `1.2` / `18px` 这类差异导致显示与实际不符
- **事件穿透**：面板容器已有 `stopPropagation`，展开编辑器不额外加全局监听，键盘事件只在输入框内处理

## 六、交互流程

```
激活插件 → 悬停高亮 → 点击锁定元素
   → 面板展示 Box Model + 分组样式
   → 点击某个值（如 margin 16px 9px）
       ├─ 就地变为控件（简写展开为 T/R/B/L）
       ├─ 输入新值 → 回车
       └─ 页面立刻变化，面板数值 / 线框图 / 覆盖层同步刷新
   → 行内 ↺ 重置单条，或 Header「Reset N」全部还原
   → Esc 退出检查模式：修改保留在页面上，刷新页面恢复
```

## 七、验收标准

1. 点击任意可编辑参数值，能在原位进入编辑态，且自动全选当前值
2. 回车或失焦提交后，页面元素样式立即变化，面板中该值与盒模型线框图同步更新
3. Esc 取消编辑，不产生任何页面变化
4. 长度类参数支持带单位输入，方向键 ±1、Shift+方向键 ±10
5. 颜色参数可通过取色器与文本输入修改，hex / rgb / hsl 均可识别
6. 枚举参数以下拉方式选择，选择后立即生效
7. margin / padding 点击后展开四边编辑，只改其中一边不影响其他三边原有的 inline 值
8. border 可分别编辑宽度、线型、颜色
9. 非法值被拦截并标红，页面不发生变化
10. 单条重置可将该属性恢复到编辑前状态；全部重置可一次性恢复该元素所有修改
11. 已修改项有明显视觉标记，Header 显示修改数量且仅在存在修改时可点击
12. 退出检查模式后修改仍保留在页面上，刷新页面后完全恢复
13. 明暗主题下面板编辑控件显示正常
14. v0.1–v0.3 已有功能无回归（悬停覆盖层、tooltip、拖拽缩放、复制、Show all、主题切换）
