- 测试对象：Inspect Lab Chrome 扩展（Manifest V3），版本 0.5.0
- 测试依据：`src/` 源码 + `manifest.json` + `README.md`（v0.5 页内评论）
- 测试类型：手工功能用例为主，辅以面板 UI 预览页调试；自动化列为可选后续
- 状态：**自动化已执行且缺陷已修复复测全绿（2026-11-04），见 [v0.5-test-results.md](./v0.5-test-results.md)；真实点击/截图类用例待人工**

## 2. 测试环境与准备

| 项 | 要求 |
| --- | --- |
| 浏览器 | Chrome 稳定版（≥ 109，需支持 `checkVisibility`、`color-mix`） |
| 构建 | `npm install && npm run build`，加载 `dist/` 目录；每次改动后重新 build 并在 `chrome://extensions` 刷新 |
| 测试页面 A（常规） | 任意 https 静态页，如 `https://example.com`、开发者文档站 |
| 测试页面 B（React SPA） | 任一 React 站点（dev 构建优先，可拿到 React 组件名），用于验证「复制给 AI」中的组件信息 |
| 测试页面 C（样式丰富） | 含四向 margin/padding、border、圆角、阴影、flex gap 的自建页面，用于盒模型与编辑回退 |
| 测试页面 D（SPA 路由/tab 切换） | 点击后 DOM 重渲染的页面，用于评论气泡重定位 |
| 面板 UI 预览 | `npm run preview` → `http://localhost:5173/preview.html`（不加载扩展也能调面板） |
| 清态准备 | 用例间通过「移除评论存储」（DevTools → Extension 存储）或重装扩展复位；`localStorage.delab-theme`、`delab-panel-view` 按用例设置 |

> 注意：`manifest.json` 的 `content_scripts.matches` 与 `host_permissions` 均为 `https://*/*`，**http 页面（含 localhost）不会注入**。面板 UI 只能用 preview.html 预览页测试。

优先级定义：P0 主流程，失败即阻塞；P1 重要分支；P2 边界/体验。

## 4. 建议执行顺序

1. 构建通过 + 加载扩展（冒烟：M1-01、M3-03、M6-03 三条主链路）
2. P0 全量（M1–M8 中标 P0 的用例）

## 5. 文档与代码差异（口径已确认 2026-11-04）

以下差异均已确认**以代码实现为准**，README 已同步更新：

1. **Esc 不退出插件**：`content-script.ts#handleKeyDown` 中 Esc 只关大图 / 收评论弹层；退出仅靠面板关闭按钮或切换器 ✕。
2. **面板位置不记忆**：`FloatingPanel.tsx#defaultPosition` 每次重开回到默认位置并清除 `delab-panel-pos`，为预期行为（M4-04 按此验收）。
3. **评论无删除入口 / 已解决即删除**：`comment-popover.ts` 仅 复制给 AI / 标记解决 / 关闭 三个操作；已解决评论从气泡与列表移除且**无「重新打开」入口**（口径 2026-11-04：等同删除，原重开按钮为不可达死代码，已移除）；`removeThread()` 暂无 UI 入口。
4. **无悬停 tooltip**：悬停只画 2px 框 + 盒模型色带（80ms 延迟）；标签名胶囊仅锁定后出现。
5. **评论气泡锚点为元素左上角**（`comment-pins.ts` paint 注释明确），非「右上角」；M6-03/M6-08 按左上角验收。
6. **尺寸模式文案为中文「填充」**（LayoutControls），对应 Fill。

## 8. 风险

| 风险 | 缓解 |
| --- | --- |
| 手工用例涉及大量视觉判断（色带、气泡避让），结果主观 | 关键用例附截图留档；必要时用 DevTools 检查浮层元素尺寸 |
| `chrome.storage`/clipboard/截屏依赖浏览器权限行为，自动化不稳定 | 优先手工验证；自动化阶段仅断言 UI 反馈（toast/列表） |
| SPA/指纹重定位依赖页面结构，第三方站点改版会导致用例失效 | 测试页面 C/D 使用自建页面固化结构 |
